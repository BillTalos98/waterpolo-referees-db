# Water Polo Referees Association — Database System

Σύστημα διαχείρισης συνδέσμου διαιτητών υδατοσφαίρισης, υλοποιημένο σε **Oracle PL/SQL**. Καλύπτει μέλη (διαιτητές, παρατηρητές, γραμματεία), ορισμούς σε αγώνες, ετήσιες δηλώσεις ενέργειας, και πλήρη οικονομική διαχείριση (αμοιβές, κρατήσεις, συνδρομές).

## Γιατί

Project εκμάθησης PL/SQL, εμπνευσμένο από το πραγματικό σύστημα του [ΣΕΔΥ](https://www.sedy.gr) (Σύνδεσμος Ελλήνων Διαιτητών Υδατοσφαίρισης). Βασίζεται σε πραγματικές επιχειρησιακές ανάγκες ενός αθλητικού συνδέσμου, όχι σε τεχνητό/θεωρητικό παράδειγμα.

## Τεχνολογία

- **Oracle Database** (PL/SQL)
- Σχεδιασμένο και δοκιμασμένο τοπικά σε **Oracle Database Free**

## Τι καλύπτει το σχήμα

**Μέλη & Ρόλοι**
- Μέλη τριών κατηγοριών (Διαιτητής, Παρατηρητής, Γραμματεία), με υποκατηγορίες διαιτητών (Α'/Β'/Γ'/Δ') και σημαία διεθνούς διαιτητή
- Ρόλοι ανεξάρτητοι από την κατηγορία μέλους — ένα μέλος μπορεί να αναλάβει διαφορετικό ρόλο σε διαφορετικό αγώνα

**Αγώνες & Ορισμοί**
- Ορισμός μελών σε αγώνες με έλεγχο ορίων ανά κατηγορία ρόλου (π.χ. max 2 διαιτητές, max 2 παρατηρητές) μέσω trigger

**Δήλωση Ενέργειας**
- Ευέλικτη δομή βασισμένη σε JSON, ώστε τα πεδία της φόρμας να μπορούν να αλλάζουν κάθε αγωνιστική περίοδο χωρίς αλλαγή στο schema
- Trigger που ενεργοποιεί αυτόματα το μέλος και ειδοποιεί τη διοίκηση με την υποβολή

**Οικονομικά**
- Ledger-based σχεδιασμός (κάθε οικονομικό γεγονός είναι μία κίνηση)
- Automated procedure υπολογισμού αμοιβών ανά κατηγορία αγώνα/ρόλο, με αυτόματη κράτηση 8% υπέρ συνδέσμου
- Views που αναπαράγουν συγκεντρωτική "Καρτέλα Μέλους" (αμοιβές, παρακρατήσεις, συνδρομές)

**Business Logic**
- Function προσδιορισμού αρχαιότητας μεταξύ διαιτητών ίδιας κατηγορίας, με κανόνα υπεροχής για διεθνείς διαιτητές

## PL/SQL χαρακτηριστικά που καλύπτει το project

- Triggers (BEFORE / AFTER INSERT, row-level)
- Stored procedures με cursor FOR loops
- Functions με έλεγχο εγκυρότητας και custom exceptions
- Views με conditional aggregation (`CASE` μέσα σε `SUM`)
- JSON storage & querying (`IS JSON`, `JSON_VALUE`)
- Custom exception handling (`RAISE_APPLICATION_ERROR`)
- Foreign keys, composite unique constraints, check constraints

## Δομή

Το πλήρες schema (πίνακες, triggers, procedures, functions, views, seed data) βρίσκεται σε ένα ενιαίο SQL αρχείο στο repository.
